# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in menei, please report it responsibly.

Send a detailed description to: security@menei.fun

Do NOT open a public GitHub issue for security vulnerabilities.

## Scope

- On-chain program logic (Rust)
- Oracle data feed integrity
- Token scoring algorithm manipulation
- SDK authentication bypass

## Response Timeline

- Acknowledgment: 24 hours
- Initial assessment: 72 hours
- Fix deployment: varies by severity
